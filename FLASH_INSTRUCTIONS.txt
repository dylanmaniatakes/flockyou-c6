==============================================================================
  FLOCKYOU -- XIAO ESP32-C6 FLASH INSTRUCTIONS
==============================================================================

HARDWARE
--------
Board:  Seeed Studio XIAO ESP32-C6
Buzzer: D2 signal, GND return

Do not flash the ESP32-S3 binaries from OuiSpy Unified Blue. Build artifacts
are CPU-, board-, flash-, and partition-specific.

INSTALL PREBUILT FIRMWARE (NO PLATFORMIO REQUIRED)
--------------------------------------------------
1. Install Python 3.
2. Install the standalone flasher dependencies:

     python3 -m pip install -r requirements.txt

3. Connect the XIAO ESP32-C6 and run:

     python3 flash.py

The repository includes all four matching ESP32-C6 images. The flasher detects
the port, asks for confirmation, writes the images, verifies them, and reboots.
Add --erase for a complete flash erase before installation.

DEVELOPMENT BUILD AND UPLOAD
----------------------------
1. Install the pinned developer tools:

     python3 -m pip install -r requirements-dev.txt

2. Build:

     pio run

3. Connect the XIAO ESP32-C6 and upload:

     pio run -t upload

4. Monitor startup at 115200 baud:

     pio device monitor -b 115200

If the port is unavailable, hold BOOT, connect USB, release BOOT, and retry.

PREPARE AND USE THE STANDALONE FLASHER
--------------------------------------
After a successful PlatformIO build:

     python3 scripts/package_firmware.py
     python3 flash.py

The packaging script refreshes these committed C6 files:

  firmware/bootloader.bin   C6 bootloader             0x0000
  firmware/partitions.bin   4 MB partition table      0x8000
  firmware/boot_app0.bin    OTA selection data        0xe000
  firmware/flockyou-c6.bin  FlockYou application      0x10000

Add --erase for a full chip erase before flashing. Add --batch to wait for and
flash multiple native-USB XIAO boards one at a time.

VERIFY THE FIRST BOARD
----------------------
1. Listen for the crow-like startup sound.
2. Confirm the serial log says BLE scanning is active.
3. Join Wi-Fi SSID "flockyou" with password "flockyou123".
4. Open http://192.168.4.1 and confirm the dashboard refreshes.
5. Test a known BLE advertisement if available.

This package has been flashed and boot-verified on a physical ESP32-C6. BLE
detection matching still needs field testing with known advertisements.
